# AI-Powered Camera Effects

A lightweight, browser-based camera web application that applies real-time visual mood filters directly to your webcam feed.

Built as part of the **"Coding with Junie, AI Agent by JetBrains"** course. With a foundational understanding of HTML and CSS, and minimal prior JavaScript experience, this project demonstrates how AI-assisted development can handle the complex canvas and media-stream mechanics, making real-time web apps accessible with clean, minimal code.

## Live Demo
Try it directly in your browser (requires camera permissions):  
👉 **[Launch AI-Powered Camera Effects](https://moonthepage.github.io/AI-Powered-Camera-Effects/)**

## Features
* **Real-Time Mood Filters:** Switch seamlessly between **Original**, **Golden**, **Rose**, **35mm**, **Daydream**, **Noir**, **Pixel**, **Halftone**, **ASCII Terminal**, **VHS/90 Broadcast**, **Risograph / Duotone**, **Architectural Blueprint**, **Prismatic Glitch** and **Phosphor CRT**.
* **100% Client-Side & Private:** Runs completely locally in your browser using HTML5 Canvas and the MediaDevices API—no photos or video streams are ever uploaded to a server.
* **Instant Snapshots:** Capture and download filtered photos directly to your device.
